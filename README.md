# System Design, in Plain English

A small web app that teaches system design step by step, in plain English, using one running example (**Shelf**, a labelling service) throughout. See [PLAN.md](PLAN.md) for the plan and [docs/AUTHORING.md](docs/AUTHORING.md) for how lessons are written.

Work in progress: the full README (running, deploying, testing) comes with the last milestone.

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # unit and content tests
npm run build    # static site in out/
```
